# C·vibe

Plataforma web de viajes construida con HTML5 y CSS3 (sin JavaScript), basada en el diseño UX/UI de Figma "C·vibe - UI/UX System".

## Páginas

- `index.html`: inicio
- `login.html`: inicio de sesión
- `explorar.html`: explorar destinos (filtros por categoría solo con CSS)
- `detalle-cartagena.html`, `detalle-tulum.html`, `detalle-santorini.html`, `detalle-tayrona.html`: detalle de cada destino
- `favoritos.html`: destinos guardados
- `itinerario.html`: itinerario por días (pestañas solo con CSS)
- `acerca.html`: acerca de C·vibe
- `style.css`: hoja de estilos compartida
- `assets/`: imágenes

## Cómo verla

Abre `index.html` en el navegador. Es mobile-first y se adapta a escritorio.
